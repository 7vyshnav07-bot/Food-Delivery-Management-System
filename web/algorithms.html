Greedy Algorithm: Nearest Delivery Option

Enter delivery options and their distances. The algorithm selects the option with the smallest distance.

Dynamic Programming: Rider Order Load Optimization

Select the highest-value combination of food orders without exceeding the rider's carrying capacity. Each order can be selected only once. Values are illustrative order values in rupees.

Available food orders

Enter an order/food name, packed weight in kg, and order value in rupees.

Backtracking: Delivery Slot Assignment

Assign each order to one of its allowed delivery slots. A slot can be used by only one order. If a choice leads to a conflict, the algorithm backtracks and tries another slot.

Enter allowed slots separated by commas, for example: Lunch A, Lunch B.
